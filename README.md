# Joshua J. P. Thompson — Academic Website

Personal academic website for Joshua J. P. Thompson, hosted with GitHub Pages.

## Structure

- `index.html` — site content
- `style.css` — layout and styling
- `script.js` — mobile navigation and small interactions

## Sections

- Research
- Selected publications
- Codes
- Talks
- CV
- Contact

## Updating the site

Most text and links can be edited directly in `index.html`. The Codes section currently contains a placeholder for a featured GitHub repository, and the CV / Scholar / ORCID / email links are intentionally left for later.
